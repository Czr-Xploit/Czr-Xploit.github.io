Download it and run it locally. The public instance is convenient, but pasting client
data into a third-party website is exactly the kind of lapse that turns an assessment
into an incident. It is a static page: it works by opening the file.

What it is **not** for: real cryptography. If you need to verify an implementation, use
the language's library. CyberChef is for understanding data, not for judging schemes.
