Lo que importa no es la herramienta, es la disciplina: **una nota por hallazgo, con la
evidencia dentro y la hora en que se obtuvo**. Cualquier editor sirve. Elijo este porque
guarda Markdown plano en tu disco, así que las notas sobreviven al programa que las creó.

Un aviso serio: si las notas contienen datos de cliente, la bóveda es material sensible.
Cifra el disco, no la sincronices a un servicio de terceros sin permiso explícito, y
bórrala cuando termine el compromiso.

<!-- en -->
What matters is not the tool but the discipline: **one note per finding, with the
evidence inside it and the time it was obtained**. Any editor does. I pick this one
because it stores plain Markdown on your own disk, so the notes outlive the program that
created them.

A serious warning: if the notes contain client data, the vault is sensitive material.
Encrypt the disk, do not sync it to a third-party service without explicit permission,
and delete it when the engagement ends.
